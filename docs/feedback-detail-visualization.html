Section 1: What You Did Well

Tone
Specific and factual. Acknowledge concrete skills the user demonstrated. No hype, no generic praise. The user should feel recognized, not patronized.
Length
2 – 4 bullet points. Each bullet is 1 sentence, 8 – 15 words.
Voice examples
✓ "Clear use of past tense in professional context."
✓ "Your intonation on questions sounded natural."

✗ "Amazing job! You're doing incredible!"
✗ "Great work on everything!"
Rule
Every strength must reference a specific skill (grammar pattern, pronunciation, vocabulary choice, register). Never generic.

Section 2: What to Work On

Tone
Direct and constructive. Frame as skill-building opportunities, not failures. Include a clear, actionable suggestion. Professional adults don't need sugar-coating — they need direction.
Length
1 – 3 items. Each item has:
• Area (2 – 4 words, the skill)
• Suggestion (1 sentence, 10 – 20 words)
• Example (optional, inline correction or tip)
Voice examples
✓ "Subjunctive mood — Practice forming subjunctive clauses in conditional scenarios."
✓ "Filler words — You used 'umm' 8 times. Try pausing silently instead."

✗ "Oops! Don't worry, your grammar needs a little work!"
✗ "Try harder next time!"
Priority system
Focus = High impact, address first
Practice = Moderate, improve over time
Polish = Minor, refinement level

Section 3: Your Progress

Tone
Data-driven and matter-of-fact. Let the numbers speak. Short metric labels with trend indicators. Professionals want measurable proof — this is their ROI on time invested.
Length
2 – 4 metric rows. Each row has:
• Metric name (1 word)
• Previous → Current (numbers)
• Trend arrow (up / stable / down)
• Message (3 – 6 words, factual)
Voice examples
✓ "Articulation 62 → 71 — Improving consistently"
✓ "Fluency 78 → 78 — Stable this week"

✗ "WOW your articulation went up SO much!"
✗ "Don't worry about fluency dropping!"
Condition
Only shows when user has ≥2 completed sessions. First session shows: "Complete one more session to see your progress trends."
