## Key Architectural Decision

**Lesson Flow Architecture:**
```
Stair tap → /lesson/[id] (carousel overview)
    ↓
START button → storeActiveLessonPlan()
    ↓
/lesson-session (orchestrator) → activity screens
    ↓
/lesson-complete (success screen with SVG rings)
```

- Lesson engine generates plans from templates based on user level + stair context
- Activity themes are defined inline (not from designSystem) for per-card flexibility
- Two-zone layout uses flex spacer for responsive distribution across device sizes
- Carousel uses horizontal snap-scrolling with FlatList, showing ~2 cards visible at a time
