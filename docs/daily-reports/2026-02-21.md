## Key Architectural Decision

**Staircase Generation Lifecycle:**
```
Onboarding scenarios → Template expansion (instant, $0) → Preview stairs
    ↓
Home screen reveal animation (typing + stagger)
    ↓
[FUTURE] First lesson content → Generated via Gemini when user taps stair
    ↓
[FUTURE] Subsequent lessons → Generated at 80% completion of previous
```

This is a **lazy generation** model — skeleton is free, content is generated only when needed. Estimated cost: ~1 Gemini API call per active lesson.
