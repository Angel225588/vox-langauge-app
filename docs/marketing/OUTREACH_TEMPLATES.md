# Vox - Outreach Templates

## Part 1: Micro-Influencer Outreach

### Who to Target

**Ideal Influencer Profile**:
- 1K-50K followers (micro/nano influencers)
- Language learning or career development niche
- Engaged audience (comments, shares)
- Authentic voice (not overly promotional)
- Posts in English, Spanish, or French

**Where to Find Them**:
- Instagram: Search #languagelearning #learnspanish #businessenglish
- TikTok: Language learning content creators
- YouTube: Polyglot channels, career advice
- LinkedIn: Career coaches, language tutors

**Red Flags to Avoid**:
- Fake followers (check engagement rate)
- Too promotional (every post is an ad)
- Irrelevant audience (gaming, fashion, etc.)
- No engagement on language content

## Part 2: Facebook Group Outreach

### Groups to Target

**Career/Professional Groups**:
- "Career Development & Professional Growth"
- "English for Professionals"
- "Business English Learners"
- "International Job Seekers"
- "Remote Work Community"

**Language Learning Groups**:
- "Learn English" (various)
- "Spanish Learners"
- "French Language Learners"
- "Polyglot Community"
- "Language Exchange"

**Cultural/Heritage Groups**:
- "Latino Community [City]"
- "French Expats"
- "Spanish Speakers in USA"

### Rules for Group Posting

**DO**:
- Read group rules first
- Provide genuine value
- Be transparent about being the founder
- Engage with comments
- Ask for feedback, not just downloads

**DON'T**:
- Spam multiple groups in one day
- Post just a link (looks spammy)
- Ignore negative feedback
- Be defensive about criticism
- Pretend to be a user

## Part 3: Response Templates

### Positive Response Handling

**When influencer says yes**:
```
Amazing, thank you so much!

Here's your access:
- App Store/TestFlight: [link]
- Your promo code (for your audience): [CODE]

No timeline pressure - use it for a week or two and share whenever feels natural. We want your honest take, positive or negative.

If you have any questions while using it, I'm here. Would love to hear what you think!
```

### Negative Response Handling

**When influencer says no**:
```
Totally understand! Thanks for considering it. If you ever want to try it in the future, the offer stands.

Keep up the great content!
```

### Handling Criticism

**When someone posts negative feedback**:
```
Thanks for the honest feedback - this is exactly what we need to hear.

You're right that [acknowledge valid point]. We're working on [improvement].

Would you be open to a quick call to tell me more about what didn't work? I want to make sure we fix this.
```
