## A/B Testing Plan

### Week 1 (Days 8-10)
- Run all 5 variations with equal budget ($1/day each)
- Track: CTR, CPI (Cost per Install), Impressions

### Week 2 (Days 11-14)
- Double budget on top 2 performers
- Pause bottom 3 performers
- Create 2 new variations based on winning themes

### Metrics to Watch
| Metric | Target | Action if Below |
|--------|--------|-----------------|
| CTR | > 1.5% | Change image/headline |
| CPI | < $1.00 | Adjust targeting |
| Install Rate | > 20% | Improve app store page |

## Image Creation Workflow

### Using Gemini (Free)
1. Go to Google AI Studio or use the Vox app's Gemini API
2. Use the prompts above
3. Generate 3-5 variations per prompt
4. Select the best one

### Adding Text in Canva (Free)
1. Upload AI-generated image
2. Add text overlay with Vox branding
3. Use colors from design system:
   - Primary: Your app's primary color
   - Text: White with shadow for readability
4. Export at 1080x1080 (square) or 1080x1920 (stories)

### File Naming Convention
```
vox_ad_[variation]_[type]_[version].png
Example: vox_ad_career_square_v1.png
```

## Copywriting Tips

### Do's
- Lead with pain points
- Use "you" and "your" frequently
- Keep sentences short
- Include social proof when available
- End with clear CTA

### Don'ts
- Don't promise fluency (unrealistic)
- Don't bash competitors by name
- Don't use jargon
- Don't make claims you can't prove
- Don't use all caps (looks spammy)
