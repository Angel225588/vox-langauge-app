# Vox Rewards System

## Philosophy

**"The only failure is not trying."**

The Vox rewards system is built on a simple truth: **trying IS winning**. In language learning, especially for "frustrated intermediates," the real enemy isn't making mistakes - it's giving up.

**Core Beliefs:**
- **Winning = Trying.** Every attempt, every word spoken, every card completed is a win.
- **Failure = Not Trying.** The only way to fail is to skip, quit, or not show up.
- **More Tries = More Rewards.** The system rewards persistence, not perfection.

This means:
- Got it wrong but tried? **You win Vox.**
- Pronunciation wasn't perfect but you spoke? **You win Vox.**
- Struggled through the whole card? **You win MORE Vox** (because you kept going).
- Skipped without trying? **No Vox** (that's the only "failure").

### Reward Calculation Function

```typescript
function calculateReward(
  cardType: CardType,
  outcome: 'correct' | 'partial' | 'incorrect' | 'skipped',
  difficulty: 'easy' | 'medium' | 'hard' | 'challenge',
  modifiers: {
    firstTry?: boolean;
    speedBonus?: boolean;
    streakDays?: number;
    perfectScore?: boolean;
    comeback?: boolean;
    dailyGoal?: boolean;
  }
): RewardResult {
  // Base points from card type
  const basePoints = CARD_BASE_POINTS[cardType];

  // Outcome multiplier
  const outcomeMultiplier = {
    correct: 1.0,
    partial: 0.6,
    incorrect: 0.3,
    skipped: 0,
  }[outcome];

  // Difficulty multiplier
  const difficultyMultiplier = {
    easy: 1.0,
    medium: 1.5,
    hard: 2.0,
    challenge: 3.0,
  }[difficulty];

  // Calculate bonus multipliers
  let bonusMultiplier = 1.0;
  if (modifiers.firstTry) bonusMultiplier += 0.5;
  if (modifiers.speedBonus) bonusMultiplier += 0.25;
  if (modifiers.streakDays) bonusMultiplier += Math.min(modifiers.streakDays * 0.1, 0.7);
  if (modifiers.perfectScore) bonusMultiplier += 1.0;
  if (modifiers.comeback) bonusMultiplier += 0.3;
  if (modifiers.dailyGoal) bonusMultiplier += 0.2;

  // Final calculation
  const finalVox = Math.round(
    basePoints * outcomeMultiplier * difficultyMultiplier * bonusMultiplier
  );

  // Skill currency (if applicable)
  const skillCurrency = CARD_SKILL_CURRENCY[cardType];
  const skillAmount = skillCurrency
    ? Math.round(skillCurrency.amount * outcomeMultiplier * difficultyMultiplier)
    : 0;

  return {
    voxEarned: finalVox,
    skillCurrency: skillCurrency ? {
      type: skillCurrency.type,
      amount: skillAmount,
    } : undefined,
    breakdown: {
      base: basePoints,
      outcome: outcomeMultiplier,
      difficulty: difficultyMultiplier,
      bonus: bonusMultiplier,
    },
  };
}
```

## Psychology Behind the System

### Why This Works for "Frustrated Intermediates"

1. **Effort Recognition** - Points for trying, not just succeeding
2. **Visible Progress** - Multiple currencies show growth in different areas
3. **Skill Balance** - Encourages working on weak areas
4. **Tangible Rewards** - Real benefits, not just virtual badges
5. **No Punishment** - Never lose points for mistakes
6. **Comeback Mechanics** - Extra bonus for trying again after failure

### Motivation Drivers

| Driver | Implementation |
|--------|----------------|
| **Autonomy** | Choose what to spend points on |
| **Mastery** | Skill currencies show competency growth |
| **Purpose** | Points connect to real language goals |
| **Progress** | Multiple visible progress indicators |
| **Social** | Tier badges, shareable achievements |

## Summary

The Vox Rewards System transforms language learning from a solitary struggle into a rewarding journey. By redefining success as **trying** rather than perfection, we remove the fear of failure that holds "frustrated intermediates" back.

**Key Principles:**
1. **Trying = Winning.** Every attempt earns Vox.
2. **Not trying = Only failure.** Skipping is the only way to fail.
3. **More tries = More rewards.** Persistence is rewarded, not punished.
4. **Multiple currencies = Multiple wins.** Track growth across different skills.
5. **Real value = Real motivation.** Rewards unlock actual features.

**The Vox Promise:**
> "Show up. Try. Win. That's it. You don't need to be perfect. You just need to try. Every word you speak, every sentence you write, every sound you hear - if you tried, you earned Vox. The only way to fail is to not try at all."

*Your voice has value. Every attempt is a victory.*
