Changes Applied

Glass Container Pattern — 5 targeted fixes
1

KPI Boxes — Color-World Gradient Fill

Each KPI box receives a vertical gradient from its color at 10% opacity to 3% opacity, plus a border at 18% opacity. The existing 3px top accent bar is retained and bumped from 60% to 80% opacity. Label and trend text now inherit the card's color instead of neutral gray.

background: rgba(255,255,255,0.05) → linear-gradient(color 10% → color 3%)
border: rgba(255,255,255,0.06) → border: rgba(color, 0.18)

2

Quick Action Buttons — Tinted Chip Style

Sprint, Random, and Weak Areas buttons switch from white-opacity ghost chips to tinted glass chips matching their color world (amber, purple, rose). Background at 8% opacity, border at 15% opacity. Icon container bumped to 18%.

bg: rgba(255,255,255,0.05) → bg: rgba(color, 0.08)
border: rgba(255,255,255,0.06) → border: rgba(color, 0.15)

3

Practice Grid Cards — Full Glass Containers

All 6 grid cards (Vocabulary, Reading, Writing, Listening, Library, Flow) switch from card.color + '08' (3% opacity ghost) to the full glass container pattern: vertical gradient from color at 10% to 3%, border at 18% opacity. Each card is now instantly distinguishable by its color tint.

4

Grid Icon Boxes — Increased Visibility

Icon container backgrounds inside grid cards are bumped from card.color + '18' (~9%) to 15% background with a 25% border. This makes the icon area pop as a distinct element within the card.

bg: rgba(color, 0.09) → bg: rgba(color, 0.15) + border rgba(color, 0.25)

5

Voice Conversation Hero — No Change

The blue gradient hero card already uses a proper multi-stop gradient (#1E3A8A → #3B82F6 → #6366F1) with a visible border. It serves as the design reference that the other elements are now matching in approach.
