Feedback Chips — Situation Analysis & Framework

UI/UX audit of feedback card visual hierarchy on dark backgrounds. Vox Language App.

Situation Analysis — The Problem

Why the current chips don't work

1
Zero visual distinction — All 3 sections use the same rgba(255,255,255,0.03) background. Strengths look identical to Improvements. The user's brain has to read every title to know which section they're in.
2
Card background = Page background — 3% white opacity on #0A0E1A is visually invisible. The "boxes" don't exist as separate objects. Same problem as the Revolut screenshot — everything blends into a dark wall.
3
Borders too subtle — 1px at 6% opacity is perceived as "no border" on dark backgrounds. Cards have no edge, no boundary, no container feeling.
4
No semantic color coding — Green = good, Blue = work on it, Purple = progress. The current design doesn't use color to convey meaning. Users must READ to understand — they can't SCAN.
5
No fixed rhythm — Variable chip heights create uneven visual flow. The eye has no anchor points. Items feel like a continuous list, not distinct pieces of feedback.

Framework — 5 Principles

How every chip must be built

1
Left accent bar (3px) — The fastest visual cue. Color-coded per section: green (strength), blue (improvement), purple (progress). Visible from peripheral vision. Identity
2
Tinted background (6% of section color) — Not white glass, but COLORED glass. Green tint for strengths, blue tint for improvements. Creates a visible surface that separates from the page. Surface
3
Fixed minimum height (48-52px) — Every chip has a consistent minimum. Creates visual rhythm. The eye knows exactly where each feedback item starts and ends. Rhythm
4
Asymmetric borders (top 10%, sides 6%) — Top border slightly brighter than sides creates a subtle "shelf" effect. The chip feels like a real object sitting on the page, not a drawn rectangle. Depth
5
One clear purpose per chip — Each chip answers exactly one question. Strength chip = "What specific skill was good?" Improvement chip = "What area + what to do about it?" Progress chip = "Am I getting better?" Clarity
