What Changed (v1 → v2)

  • Score Comparison Card — Scores live inside a glass card with a "Comprehension" header. Before/After rings are side-by-side with an arrow and delta pill between them. Percentages shown below each score for clarity.
  • Improvement Bar — Visual bar showing 33% → 100% progress. Layered: gray ghost bar for "before", teal gradient bar for "after". Makes the improvement tangible at a glance.
  • Session Summary Card — Four rows with colored icons: Words learned (teal), Points earned (blue), Time spent (purple), Day streak (amber). Each has its own color world. Replaces the single floating points badge.
  • Celebration Header — Checkmark icon + lesson title + scenario name. Lighter, less dramatic than v1's generic "Your Progress". Tells the user what they completed.
  • Motivational Message — More specific: "From 1 to 3 — real improvement" instead of generic "Impressive growth". References the scaffolding loop working.
  • Information density — More data in the same space without feeling cluttered. Words learned, points, time, streak all visible. The user walks away knowing exactly what they gained.
